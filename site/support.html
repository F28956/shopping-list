Support

For app version 1.0

Getting connected

Shopping List needs a server before it needs an account. On first launch it asks for the server address — something like https://lists.example.com. Enter it, sign in with Google, and you are in.

To change the address later, open Settings → Server in the app. Changing it signs you out and clears the lists cached on the device, because those belong to the old server.

When something is wrong

“This account may not use this server”

You signed in successfully, and the server does not admit you. This is not a mistake you can fix from the app — whoever runs the server decides which addresses may sign in. Ask them to add yours, then sign in again.

The app cannot reach the server

  • Check the address for a typo, and include https:// or http://.
  • If the server is on your home network, the phone has to be on that network too. An address like localhost means the phone itself and will never work.
  • Android blocks plain http:// connections by default. A server on the open internet should be served over https://; a server on a home network may need the app to be built to allow that host.

The list is there but nothing can be added

The app shows the list you last loaded when it cannot reach the server, and says so at the top of the screen. Reading works; adding and ticking off need the connection back.

The watch shows nothing

The watch app asks the paired iPhone for the credential and the server address. Open the app on the phone once, then try the watch again.

A share link does not work

Share links are good for one person and seven days. Once somebody has used a link it grants nothing to anybody else, including someone already on the list. Ask for a fresh one.

Running the server

The server is a single binary with a single SQLite file beside it. The first person to sign in claims the server and can then admit everybody else by email address. Removing an address ends that person's session on their next request.

Deleting your data

Ask whoever runs the server to close your account. That removes your lists, items, notes and purchase history. If you run the server, the whole database is one file you control.
