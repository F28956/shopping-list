iPhone and Apple Watch

Install on this iPhone Open this page in Safari and tap

The Watch app comes with it. It lives inside the iPhone app, so there is nothing separate to install — open the Watch app on your phone after this finishes and it will be there, or already on its way.

If tapping does nothing, you are not in Safari. Other browsers on iOS ignore this kind of link silently.

If it says the app cannot be installed, this device has not been registered. Send whoever runs the server your device’s identifier — Settings → General → About → scroll down.

Android

Download the APK Android 8 and later
  1. Tap the file once it has downloaded.
  2. Android will say this browser is not allowed to install apps. Allow it — the setting is per-app and you can turn it back off afterwards.
  3. Tap install.

To be told about updates rather than checking, add this address to Obtainium.

Then what

The app opens straight onto a list of its own and needs nothing else. To put it on the server, open Settings → Server, enter the address, and sign in. Anything already on the device goes up with you.

The server address must be https://. These are release builds and they refuse plain HTTP — the token in every request is a bearer credential, and on plain HTTP it travels in the clear.
